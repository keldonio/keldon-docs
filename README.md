# keldon-docs

Source content for the [Keldon](https://github.com/keldonio/keldon-operator) documentation, published at [keldon.io/docs](https://keldon.io/docs/).

## What's in here

This repository contains the Markdown source for all versioned Keldon documentation. 

## Structure

Docs are organized by release version (e.g. `v0.11.1/`) so multiple versions can be published and browsed side by side.

## Contributing

Documentation improvements are one of the easiest ways to contribute to Keldon, even without touching Go code. If you find something unclear, outdated, or missing:

1. Fork this repository
2. Edit or add the relevant Markdown file
3. Open a pull request

Good first contributions are tagged `good-first-issue`.
